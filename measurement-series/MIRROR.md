# The measurement series — mirror

This directory mirrors the published repository *The Key Question* (Nullius 2140), https://github.com/Nullius2140/the-key-question, at commit `30c95d8` (12 September 2026): 89 files, byte for byte, including the OpenTimestamps proofs. Nothing here is edited; every hash in its `VERIFICATION.md` and `r2-adjudication-manifest.txt` can be checked against the files beside them.

The canonical home of the measurement series is that repository. This mirror exists so that the essays' sentence — one repository for the three essays, their companion paper, the measurement series and the manifest of every anchor — is true of this repository as well, and so that a reader of the revised essays finds the measurements they rest on without leaving it.

If a file here and the file at the canonical home ever differ, the canonical home — and behind it the chain — is right.
